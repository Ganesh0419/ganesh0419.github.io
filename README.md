# Ganesh Tayade portfolio

A portfolio built with plain HTML, CSS and JavaScript. There is nothing to install or build.

## Put it online with GitHub Pages

1. Create a public repository named `YOUR-USERNAME.github.io`.
2. Upload everything inside this folder to the top level of the repository, including `.nojekyll`.
3. In the repository, open **Settings > Pages**. Under **Source**, choose **Deploy from a branch**, then pick `main` and `/ (root)`.
4. After a minute or two the site is live at `https://YOUR-USERNAME.github.io`.

## Update the content

Edit `js/content.js` to add your showreel link, social links and projects. Put project images and reels in `assets/`. Each project can list `clips` (vertical reels) that preview on hover and open in a full-screen player.

## Files

- `index.html`: the page and its text
- `css/style.css`: all styles, including the A4 print layout
- `js/film.js`: the film, timeline and keyboard shortcuts
- `js/content.js`: projects and links
- `Ganesh_Tayade_Resume.pdf`: the public resume, without a phone number
